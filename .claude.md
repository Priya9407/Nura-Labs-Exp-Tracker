# Nura Experiments Platform - Claude Instructions

## Project Overview
Full-stack experiment management platform with:
- **Frontend**: React + Vite + CSS Variables (light/dark theme)
- **Backend**: Flask + MongoDB + Redis
- **Auth**: Session-based with Redis store
- **Features**: Experiment lifecycle, observations, team management

## Quick Commands
```bash
# Start all services
docker-compose up -d

# View logs
docker-compose logs -f app

# Restart backend
docker-compose restart app
```

## Key Backend Endpoints

### Auth
- `POST /api/auth/login` - Login with email/password
- `POST /api/auth/logout` - Logout
- `POST /api/auth/forgot-password` - Send new temp password
- `POST /api/auth/change-password` - Change password (requires current)

### Users
- `POST /api/users/invite` - Invite new user (admin only)
- `GET /api/users` - List all users
- `POST /api/users/:uuid/blacklist` - Blacklist user
- `POST /api/users/:uuid/unblacklist` - Remove from blacklist

### Experiments
- `GET /api/experiments` - List experiments
- `POST /api/experiments` - Create experiment
- `GET /api/experiments/:uuid` - Get experiment details
- `POST /api/experiments/:uuid/start-building` - Start build phase
- etc.

## Common Issues & Fixes

### Screen goes black on mobile
- Check `AppLayout.jsx` for misplaced hooks
- Ensure all `useState` calls are inside component body
- Verify no CSS conflicts between `global.css` and `main.css`

### Login not working
- Check Redis connection: `docker exec experiment-redis redis-cli ping`
- Verify MongoDB is running: `docker ps`
- Check logs: `docker-compose logs app`

### Changes not reflecting
- Frontend: Hard refresh browser (Ctrl+Shift+R)
- Backend: Restart container: `docker-compose restart app`
